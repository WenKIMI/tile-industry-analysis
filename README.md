# 瓷砖行业景气分析（2026Q3 起）

> 基于行业景气的瓷砖磨具耗材需求代理分析 —— 指标树、证据链与季度验证

## 这个项目在做什么

回答三个问题，每季度一次：

1. 未来 2-4 个季度，瓷砖行业景气往哪个方向走？
2. 传导到磨具耗材（磨边轮、抛光磨块）和压机模具，需求含义是什么？
3. 哪些证据会证伪这个判断？

## 这个项目不做什么

- **不预测股票**。不预测瓷砖股，也不预测磨具股。
- 不做周频、不做高频。瓷砖是低频行业，硬做高频只会放大噪声。
- 不用 LLM 下结论。方向由评分卡决定，LLM 只做证据抽取和文字组织。

## 方法：一条链，五个环节

```
指标树定口径  →  评分卡算景气  →  LLM 抽证据  →  季度报告  →  预测日志复盘
   （结构）        （结论）          （支撑）        （表达）      （自我校准）
```

关键设计：**结论和证据分离**。评分卡产出数字，证据只负责解释数字，两者互不覆盖。
这样做是为了防止"先有结论再找证据"——这是行业研究里最常见的失败模式。

| 类别 | 指标 | 权重 | 方向 |
|---|---|---|---|
| 需求 | 地产竣工面积同比 | 15% | 正 |
| 需求 | 瓷砖产量同比 | 15% | 正 |
| 需求 | 瓷砖出口金额同比 | 10% | 正 |
| 需求 | 商品房销售面积同比 | 5% | 正 |
| 价格 | 瓷砖价格指数 | 10% | 正 |
| 盈利 | 上市公司毛利率 | 10% | 正 |
| 政策 | 地产政策强度 | 10% | 正 |
| 供给 | 行业开工率 | 5% | 正 |
| 供给 | 库存天数 | 5% | 负 |
| 成本 | 能源成本（天然气） | 5% | 负 |
| 信用 | 应收账款周转天数 | 5% | 负 |
| 政策 | 环保/能耗政策 | 5% | 负 |

见 `indicator_tree.xlsx`。每个指标都标了「可获取性」：直接 / 代理 / 手工 / 需核实。

## 权重怎么来的（这一节比权重本身重要）

**坦白说：这 12 个权重是主观赋值（expert judgment），不是统计估计。**

它们来自项目初始方案的行业判断——"哪个环节更直接决定瓷砖景气，权重就给高"。这个理由不假，
但它**无法被证明**：没人能证明 15% 比 14% 更对。

更完整的方法论、为什么不用 IC / 回归 / PCA、以及变更纪律，见 **[`docs/权重说明.md`](docs/权重说明.md)**。

### 所以做了一次敏感性测试

用 `src/weight_sensitivity.py` 跑四类检验（2026Q3 数据）：

| 权重方案 | 景气分 | 分级 |
|---|---|---|
| 基线（当前） | -0.300 | 中性震荡 |
| 等权（各 8.33%，最不主观） | -0.417 | 中性震荡 |
| 需求类 ×1.5 | -0.408 | 中性震荡 |
| 政策类 ×2 | -0.130 | 中性震荡 |
| **剔除政策类** | **-0.529** | **景气下行** |
| 财报类 ×1.6 | -0.372 | 中性震荡 |

随机扰动权重 2 万次的结果：

| 扰动强度 | 上行 | 中性 | 下行 |
|---|---|---|---|
| 强 | 10.0% | 51.9% | 38.1% |
| 中 | 3.4% | 63.2% | 33.4% |
| 弱 | 0.6% | 72.3% | 27.1% |

**三个结论：**

1. **「不是上行」最稳**——所有方案里上行概率最高只有 10%。
2. **「中性」这个档位不牢靠**——约 1/4~1/3 的概率会变成「下行」。
3. **整套结论最脆弱的一环是政策打分，不是权重**：剔除政策那 10%，立刻翻成下行。
   而政策分（3/3）本身是主观打的。

**因此：分数值没有精度意义。** `-0.30` 里的 `.30` 是假精度，只能说"中性偏弱"，
不能写"景气度 -0.30，较上季下降 0.05"。

## 磨具映射：为什么必须分两个分

| 磨具品类 | 驱动变量 | 时滞 |
|---|---|---|
| 磨边/抛光耗材 | 瓷砖**产量**、开工率、大规格占比 | 同步或略滞后 |
| 压机模具 | 瓷砖企业**资本开支**、新增产线、技改 | 领先 1-2 季 |

耗材是「消耗品」，跟着产量走；模具是「设备」，跟着扩产走。两者周期不同，合成一个分会互相抵消，
所以项目里始终分成 **耗材代理分** 和 **模具代理分** 两个独立指标。

## LLM 做了什么、没做什么

**做了：**
- 从政策文件、协会报告、财报、新闻中抽取结构化证据（`prompts/01`）
- 按固定字段标注：来源、日期、事实类型、影响环节、是否传导到磨具、方向、强度、可信度
- 财报数据抽取与口径提示（`prompts/03`）
- 反方检查，专门找证伪证据（`prompts/04`）
- 按模板组织报告文字（`prompts/05`）

**没做：**
- 不下行业好坏的结论
- 不生成任何原始数字（所有数字来自 `data/raw.csv` 或原文摘录）
- 不参与权重设定和打分决策

每条 LLM 产出都要过「溯源 / 查数 / 查类型」三道校验，任一条过不了就整批重跑。

## 怎么用（每周约 2 小时）

> **第一次上手，先读 `docs/操作指导书.docx`。** 它把 8 周拆成可打勾的步骤，
> 每个指标去哪拿、Excel 里填哪一格、什么时候算做完，都写清楚了。

```powershell
# 1. 把新数据录进 src/fill_raw_qX.py，跑它写入 data/raw.csv
#    （用脚本而不是手填，是为了让每一行都带来源和链接，形成可审计台账）
py -3.13 src/fill_raw_q3.py

# 2. 算建议得分
py -3.13 src/score.py

# 3. 把建议分回填进 scorecard.xlsx
py -3.13 src/fill_scorecard.py

# 4. 对判断不一致的指标，改 src/adjust_scores.py 里的 OVERRIDES 再跑
#    （必须写清理由；这一步会独立复算全部结果，不依赖 Excel）
py -3.13 src/adjust_scores.py

# 5. 跑权重敏感性，把概率分布写进报告附录
py -3.13 src/weight_sensitivity.py
```

> 第 1 步需要 `openpyxl` 的脚本（`fill_scorecard` / `adjust_scores` / `weight_sensitivity`）
> 请用带 openpyxl 的解释器跑；`score.py` 只依赖 pandas，用 `py -3.13` 即可。

最后打开 `scorecard.xlsx` 的「汇总」Sheet 看数字（公式需要 Excel 打开才会计算），
若景气分跨越 ±0.5 边界，在 `forecast_log.xlsx` 登记一次判断。

重新生成 Excel（改了指标或权重后）：

```powershell
py -3.13 src/build_workbooks.py
```

## 验证与复盘

`forecast_log.xlsx` 记录每次判断：方向、置信度、依据、验证指标、验证日期、实际结果、对错、错因。

错因只分五类：**数据问题 / 逻辑问题 / 时点问题 / 证据问题 / 运气**。

**样本只有几个季度，禁止为了「历史全对」反复调权重。** 复盘看逻辑是否成立、是否可证伪，不看回测胜率。

## 局限性（写在这里，比藏在心里好）

1. **权重是主观赋值**：12 个权重来自行业经验判断，没有统计依据。敏感性测试显示
   "中性"档位有 1/4~1/3 概率翻成"下行"，且结论高度依赖主观的**政策打分**。详见 `docs/权重说明.md`。
2. **数据可得性**：协会数据多为付费或摘要。价格、开工率、环保政策三项只能用"定性档位"，
   不能算同比、不能画趋势线。
3. **口径风险**：瓷砖产量统计口径历史上有调整，且目前用的是**代理值**（三家上市公司营收同比），
   不是协会产量口径，误差方向未知。
4. **总量代理的偏差**：35% 权重来自同三家公司（产量、毛利、库存、应收），
   反映的是"三家公司"而非"行业"，东鹏一家的波动就能改变全表得分。
5. **传导链假设未经验证**：产量→耗材、资本开支→模具 这两条链是行业经验推断，
   样本期内验证不出统计显著性。
6. **归因不纯**：磨具需求还受石材、玻璃、出口影响，本项目只能做方向性代理，不能定量拆分。
7. **样本量小**：季度数据点太少，任何"显著"结论都不可靠，只能做方向判断。
   所有分数都是"1 期截面"，不存在"较上季变化"这回事。

## 数据来源

全部公开渠道：

- 国家统计局（地产竣工、销售、工业产品产量）
- 海关总署（出口）
- 巨潮资讯网（东鹏控股、蒙娜丽莎、帝欧家居、奔朗新材、科达制造财报与公告）
- 中国建筑卫生陶瓷协会（公开报告摘要）
- 公开新闻（价格战、环保停限产、地产政策）

**合规声明**：不抓取付费研报，不使用内幕信息，所有数据标注来源与链接。研报仅作观点样本，不作为数据来源。

| 项 | 值 |
|---|---|
