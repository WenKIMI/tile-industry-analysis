# 瓷砖行业景气分析（2026Q3 起）

> 基于行业景气的瓷砖磨具耗材需求代理分析 —— 指标树、证据链与季度验证

## 这个项目在做什么

回答三个问题，每季度一次：

1. 未来 2-4 个季度，瓷砖行业景气往哪个方向走？
2. 传导到磨具耗材（磨边轮、抛光磨块）和压机模具，需求含义是什么？
3. 哪些证据会证伪这个判断？

## 这个项目不做什么

- **不预测股票**。不预测瓷砖股，也不预测磨具股。
- 不做周频、不做高频。瓷砖是低频行业，硬做高频只会放大噪声。
- 不用 LLM 下结论。方向由评分卡决定，LLM 只做证据抽取和文字组织。

## 方法：一条链，五个环节

```
指标树定口径  →  评分卡算景气  →  LLM 抽证据  →  季度报告  →  预测日志复盘
   （结构）        （结论）          （支撑）        （表达）      （自我校准）
```

关键设计：**结论和证据分离**。评分卡产出数字，证据只负责解释数字，两者互不覆盖。
这样做是为了防止"先有结论再找证据"——这是行业研究里最常见的失败模式。

## 指标树（12 个指标，权重合计 100%）

| 类别 | 指标 | 权重 | 方向 |
|---|---|---|---|
| 需求 | 地产竣工面积同比 | 15% | 正 |
| 需求 | 瓷砖产量同比 | 15% | 正 |
| 需求 | 瓷砖出口金额同比 | 10% | 正 |
| 需求 | 商品房销售面积同比 | 5% | 正 |
| 价格 | 瓷砖价格指数 | 10% | 正 |

| 政策 | 地产政策强度 | 10% | 正 |
| 供给 | 行业开工率 | 5% | 正 |
| 供给 | 库存天数 | 5% | 负 |

见 `indicator_tree.xlsx`。每个指标都标了「可获取性」：直接 / 代理 / 手工 / 需核实。

## 磨具映射：为什么必须分两个分

| 磨具品类 | 驱动变量 | 时滞 |
|---|---|---|
| 磨边/抛光耗材 | 瓷砖**产量**、开工率、大规格占比 | 同步或略滞后 |
| 压机模具 | 瓷砖企业**资本开支**、新增产线、技改 | 领先 1-2 季 |

耗材是「消耗品」，跟着产量走；模具是「设备」，跟着扩产走。两者周期不同，合成一个分会互相抵消，
所以项目里始终分成 **耗材代理分** 和 **模具代理分** 两个独立指标。

## LLM 做了什么、没做什么

**做了：**
- 从政策文件、协会报告、财报、新闻中抽取结构化证据（`prompts/01`）
- 按固定字段标注：来源、日期、事实类型、影响环节、是否传导到磨具、方向、强度、可信度
- 财报数据抽取与口径提示（`prompts/03`）
- 反方检查，专门找证伪证据（`prompts/04`）
- 按模板组织报告文字（`prompts/05`）

**没做：**
- 不下行业好坏的结论
- 不生成任何原始数字（所有数字来自 `data/raw.csv` 或原文摘录）
- 不参与权重设定和打分决策

每条 LLM 产出都要过「溯源 / 查数 / 查类型」三道校验，任一条过不了就整批重跑。

## 怎么用（每周约 2 小时）

> **第一次上手，先读 `docs/操作指导书.docx`。** 它把 8 周拆成可打勾的步骤，
> 每个指标去哪拿、Excel 里填哪一格、什么时候算做完，都写清楚了。

```powershell
# 1. 把新数据录进 data/raw.csv（一行一个数据点）
# 2. 算建议得分
py -3.13 src/score.py

# 3. 打开 scorecard.xlsx，对照 data/scorecard_auto.csv 填「得分」列
#    不同意的直接改，并在「打分依据」写清为什么改
# 4. 看「汇总」Sheet 的景气分和磨具两个代理分
# 5. 若景气分跨越 ±0.5 边界，在 forecast_log.xlsx 登记一次判断
```

重新生成 Excel（改了指标或权重后）：

```powershell
py -3.13 src/build_workbooks.py
```

## 验证与复盘

`forecast_log.xlsx` 记录每次判断：方向、置信度、依据、验证指标、验证日期、实际结果、对错、错因。

错因只分五类：**数据问题 / 逻辑问题 / 时点问题 / 证据问题 / 运气**。

**样本只有几个季度，禁止为了「历史全对」反复调权重。** 复盘看逻辑是否成立、是否可证伪，不看回测胜率。

## 局限性（写在这里，比藏在心里好）

1. **数据可得性**：协会数据多为付费或摘要，开工率、库存天数只能代理估算。
2. **口径风险**：瓷砖产量统计口径历史上有调整，跨年同比前必须确认可比性。
3. **传导链假设未经验证**：产量→耗材、资本开支→模具 这两条链是行业经验推断，样本期内可能验证不出统计显著性。
4. **归因不纯**：磨具需求还受石材、玻璃、出口影响，本项目只能做方向性代理，不能做定量拆分。
5. **样本量小**：季度数据点太少，任何"显著"结论都不可靠，只能做方向判断。

## 数据来源

全部公开渠道：

- 国家统计局（地产竣工、销售、工业产品产量）
- 海关总署（出口）
- 巨潮资讯网（东鹏控股、蒙娜丽莎、帝欧家居、奔朗新材、科达制造财报与公告）
- 中国建筑卫生陶瓷协会（公开报告摘要）
- 公开新闻（价格战、环保停限产、地产政策）

**合规声明**：不抓取付费研报，不使用内幕信息，所有数据标注来源与链接。研报仅作观点样本，不作为数据来源。
