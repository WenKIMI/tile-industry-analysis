# 政策解读 Prompt

用途：地产政策、环保/能耗政策文件 → 结构化影响判断。
政策是本项目里唯一的「手工打分」环节，也是最容易变成"看新闻猜情绪"的地方，所以要强制结构化。

---

## Prompt

```
阅读以下政策文件，抽取结构化信息。区分事实与推断，每条给出来源和日期。

1. 政策目标：要解决什么问题（一句话）
2. 政策工具：具体手段（信贷/限购/补贴/环保限产/能耗双控/标准提升）
3. 对瓷砖需求的影响：方向（利多/利空/中性）+ 强度（高/中/低）+ 作用时滞（当月/1-2 季/更长）
4. 对瓷砖供给的影响：同上
5. 对成本的影响：同上（能源、环保改造投入）
6. 时间节奏：什么时候开始生效，是脉冲式还是持续性
7. 受益环节 / 受损环节
8. 原文依据：逐条列出支撑上述判断的原文句子

约束：
- 「政策提到」不等于「政策落地」，落地与否必须单独标注。
- 没有明确执行细则的，影响强度最高只能标「中」。
- 不要引用文件里没有的数字。

政策文件：
---
{document}
---
```

## 地产政策强度打分规则（自己定，写死，别每次凭感觉）

每月给 0-3 分，只数**实质性的、全国性的**政策：

| 分档 | 判定标准 |
|---|---|
| 3 | 全国性需求刺激（降首付/降利率/放松限购）+ 有明确执行时间 |
| 2 | 全国性表态 + 部分城市落地 |
| 1 | 只有地方性政策，或只有表态无细则 |
| 0 | 本月无实质政策 |

**关键纪律**：同一份文件不重复计分；政策"喊话"与"落地"分开记，月底只记落地的那部分。

---

## 环保/能耗政策打分规则

每季给 -2 ~ 0 分（负向指标：越严越负）：

| 分档 | 判定标准 |
|---|---|
| -2 | 主产区（佛山/淄博/高安等）大范围停限产，影响面 > 30% 产能 |
| -1 | 局部停限产或环保成本明显上升 |
| 0 | 无实质变化 |

注意：环保限产对**瓷砖产量**是利空，但对**瓷砖价格**可能是利多（供给收缩）。
这就是为什么必须分环节标注——同一个政策在不同环节方向相反是常态。
