# 反方检查 Prompt（红队）

用途：专门对抗自己的确认偏误。**这一步比证据抽取更重要**，因为人一旦有了结论，就只会看见支持它的证据。

---

## Prompt A：找反例

```
针对以下主叙事，找出 3 条最强反例证据，并说明每条为什么可能证伪它。

要求：
1. 不要重复任何支持性证据。
2. 每条反例必须指明：它推翻了链条的哪一环、需要多大强度才能推翻。
3. 如果找不到足够强的反例，明说"未找到"，不要凑数。
4. 反例优先选「可观测的、下个季度就能验证的」，而不是抽象风险。

主叙事：
---
{你的判断，例如：瓷砖产量同比连续两季为负，磨边耗材需求将在未来 2 个季度承压}
---
```

---

## Prompt B：换一个身份重看

```
你现在是一位看空这个判断的分析师。请用最有力的逻辑反驳下面这段结论，
指出其中隐含的、没有被证实的假设。

结论：
---
{你的判断}
---
```

同一个模型换个身份，往往会给出完全不同的答案——这不是它不稳定，是它此前在顺着你说。**两个答案都留着**，写进报告的「分歧与矛盾」一节。

---

## Prompt C：预演打脸

```
假设 6 个月后证明我这次判断是错的。请写出最可能的 3 个具体原因，
按可能性排序，并给出每个原因在当下可以观察到的早期信号。
```

---

## 本项目最常见的 5 个盲点（每次红队必查）

1. **非瓷砖下游托底**：石材、玻璃、日用陶瓷同样消耗磨具。磨具公司营收没跌，可能只是瓷砖占比在下降。
2. **出口替代**：国内产量下滑，但出口或海外产能补上了，磨具需求未必同步下滑。
3. **库存缓冲**：渠道库存和厂商库存会平滑短期波动，产量下滑 1 个季度不等于耗材需求立刻下滑。
4. **结构升级对冲**：大规格/岩板占比提升，单平方米耗材消耗和单价都在上升，能部分抵消产量下滑。
5. **价格战的双向性**：瓷砖降价 → 磨具被压价（利空），但同时可能刺激瓷砖销量（利多）。方向不唯一。

---

## 使用节奏

- 每次给出季度判断前，**必跑 A**。
- 每季度复盘时，跑一次 C，把上次的"预演打脸原因"和实际结果对照。
- 连续两次判断都被同一个盲点打中，说明指标树缺了一个维度，回去改结构，而不是调权重。
