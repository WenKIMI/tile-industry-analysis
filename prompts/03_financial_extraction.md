# 财报 / 电话会抽取 Prompt

对象：东鹏控股、蒙娜丽莎、帝欧家居（瓷砖端），奔朗新材、科达制造（磨具端验证）。
数据源：巨潮资讯网公开财报、公开电话会记录。

---

## Prompt

```
从以下财报 / 电话会记录中抽取信息。只抽取原文明确写出的内容，
不推断、不补全、不做同比测算（原文给了同比才写）。

一、经营数据
1. 营业收入及同比增速
2. 归母净利润及同比增速
3. 毛利率（及同比变化 pp）
4. 应收账款余额、应收账款周转天数
5. 存货余额、存货周转天数
6. 资本开支 / 在建工程 / 购建固定资产支付的现金
7. 分产品收入（瓷砖 / 卫浴 / 其他）及占比
8. 分渠道收入（工程 / 经销 / 出口）及占比

二、管理层表述（逐条摘录，不要改写）
9. 对需求的描述（原话）
10. 对价格的描述（是否提到价格战、提价、降价）
11. 对产能 / 开工率的描述
12. 对下游客户（地产商）账期与回款的描述
13. 对未来的指引（如有）

三、口径提示
14. 是否发生会计政策变更、口径调整、并购重组导致不可比
15. 报告期是单季度还是累计（必须标明）

输出：Markdown 表格 + 原文摘录列。没有的项目写「未披露」，不要留空、不要填 0。
```

---

## 抽取后必做的交叉验证

拿到数字先别急着填 Excel，做这三个检查：

1. **同比互验**：本期值 / (1+同比) ≈ 上期值。对不上就是抓错了数（或口径变了）。
2. **三表勾稽**：营收增速与应收账款增速差太多，说明可能在放宽信用换收入——这本身就是一条重要证据。
3. **单季 vs 累计**：半年报的"营业收入"是半年累计，别当成 Q2 单季。这是最高频的错误。

## 瓷砖公司看什么（三家对比时的关注点）

| 指标 | 为什么重要 |
|---|---|
| 毛利率同比 | 价格战最直接的证据；下滑快于成本下降 = 在让价 |
| 应收账款周转天数 | 景气下行时最先恶化的指标，比营收更早 |
| 资本开支 | 决定 1-2 季度后的压机模具需求 |
| 工程渠道占比 | 占比越高，受地产客户拖累越直接 |
| 存货周转天数 | 与开工率互为印证 |

---

## 磨具端验证（滞后一个季度看）

- **奔朗新材**：营收增速、毛利率、应收账款周转 → 验证"磨边耗材跟产量"这条链
- **科达制造**：陶瓷机械收入 → 验证"压机模具跟资本开支"这条链

如果瓷砖产量已经连续两个季度下滑，但磨具公司营收还没掉，先别急着说"传导失效"——
要确认磨具公司的收入确认时点和客户结构（是否有石材/玻璃等其他下游在托底）。
