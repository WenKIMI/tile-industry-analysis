### 这份指导书解决什么问题

你手上已经有一套做好的工具（三个 Excel、五个 Prompt、一个评分脚本）。

### 2.1 先钉死四个口径（30 分钟，写进 `indicator_tree.xlsx` 的「口径说明」Sheet）

| 问题 | 建议答案 | 为什么 |
|---|---|---|
| 行业范围 | 建筑陶瓷/瓷砖，**不含卫生洁具** | 卫浴的下游和周期完全不同，混进来会污染信号 |
| 下游拆分 | 工程 / 零售 / 出口 | 三条链对政策的敏感度差异极大 |
| 磨具范围 | 只做磨边抛光耗材 + 压机模具 | 其他磨具（如金刚石锯片）下游太杂 |
| 数据基准年 | 2020 年至今 | 再往前地产周期性质变了，可比性差 |

**口径一旦定了，8 周内不许改。** 改了要重做历史数据，等于白干。

### 2.2 数据可得性核查（重要，先看这个再动手）

我按公开渠道核实了一遍，你的原始计划里有一处需要调整：

> **⚠️ 瓷砖产量的「月度」数据大概率拿不到。**
> 全国瓷砖产量（2025 年约 48.6 亿㎡）主要由**中国建筑卫生陶瓷协会**按**年度/季度**发布，
> 统计局月度工业产品产量这条线近年不稳定，口径也调整过。

**这不是坏消息，是让你少走弯路。** 应对办法：

| 做法 | 说明 |
|---|---|
| 产量改用**季度/年度** | 在 `raw.csv` 里如实标注频率，别硬凑月度 |
| 月度空缺用**代理** | 上市公司季度营收增速、瓷砖出口金额、产区开工新闻 |
| 评分卡里**按季度打分** | 12 个指标里只有 4 个是月频，混合频率时以季频为准更新 |

**结论：这个项目的节奏应该是「季度打分、月度观察」，不是月度预测。**
这反而符合你在 README 里写的"不做周频高频"的定位。

### 2.4 raw.csv 到底怎么填

**格式：一行一个数据点，同一指标按日期从上到下追加，不要覆盖。**

三个完整示例（照抄格式，换成真数）：

```csv
日期,指标,值,单位,来源,链接,备注
2026-08-31,地产竣工面积同比,-10.0,%,国家统计局,https://data.stats.gov.cn/,累计同比
2026-09-30,地产竣工面积同比,-12.5,%,国家统计局,https://data.stats.gov.cn/,累计同比
2026-08-31,上市公司毛利率,25.8,%,巨潮资讯,https://www.cninfo.com.cn/,2026Q2单季 三家均值
```

四条填写纪律：

1. **日期统一用月末/季末**（`2026-09-30`），不要写"9 月"
2. **同一指标至少录两期**，否则算不出变化（脚本会提示"只有一期"）
3. **单位必须填**，`%` / `天` / `元/吨` / `分` 不能空
4. **链接尽量填**，三个月后你会感谢自己

### 2.5 一个必须知道的量纲问题

`score.py` 里给所有指标套了同一套阈值（变化 ≥ +2 打 +2 分）。
这对**百分比指标**成立，但对下面三个不成立：

| 指标 | 单位 | +2 意味着什么 | 怎么办 |
|---|---|---|---|
| 库存天数 | 天 | 变化 2 天 | 阈值太松，实际要看 10 天以上 |
| 应收账款周转天数 | 天 | 变化 2 天 | 同上 |
| 能源成本 | 元/吨 | 变化 2 元 | 阈值几乎无意义 |

**处理办法（二选一）：**

- **推荐**：这类指标在 raw.csv 里录入**变化率**（如 `库存天数同比变化 +8%`），让所有指标统一成百分比口径
- **或者**：忽略 `score.py` 的自动建议分，在 Excel 里按历史区间手动判断

不管选哪种，**在 `indicator_tree.xlsx` 的备注列写明你选了什么**，否则三个月后的你会一头雾水。

## 3. 第 2 周：评分卡跑通

### 3.1 五档打分怎么判（别凭感觉）

| 分 | 判断标准 | 例子 |
|---|---|---|
| **+2** | 同比由负转正，且环比继续改善 | 竣工同比 -5% → +3% |
| **+1** | 同比跌幅明显收窄，或温和转正 | -12% → -6% |
| **0** | 变化在噪声范围内 | -12% → -11% |
| **-1** | 同比涨幅收窄，或温和转负 | -6% → -12% |
| **-2** | 同比由正转负，且恶化加速 | +3% → -15% |

**"明显"的定义由你定，但要先定后用。** 建议：变化幅度 ≥ 5 个百分点算"明显"。
写进「口径说明」Sheet，之后不许改。

### 3.2 对着 Excel 的操作步骤

1. 打开 `scorecard.xlsx`，先看「汇总」Sheet（第一个），现在是空的/0
2. 切到「原始数据」Sheet，把 `raw.csv` 的内容**复制粘贴**进 A 列起的表格
   （只作为留档，公式不读它）
3. 切到「评分卡」Sheet，这是主战场：
   - **E 列「最新值」**：填最新一期数字
   - **F 列「上期值」**：填上一期数字
   - **G 列「同比/变化」**：自动算，不用管
   - **H 列「得分」**：点单元格，从下拉里选 -2/-1/0/1/2
   - **J 列「打分依据」**：**必须写一句**，例如"同比 -12.5%，较上期再降 2.5pp"
   - **K 列「数据日期」**：填 2026-09
4. 看第 17 行的「景气分（加权合计）」
5. 切到「磨具代理」Sheet：
   - 4 行自动引用评分卡（不用填）
   - 3 行是手工的（大规格占比、资本开支、新增产线），填 -2~2，没数据填 0
6. 回到「汇总」Sheet 看四个数字

### 3.3 负向指标怎么填（最容易错的地方）

**不要用公式取反，直接填带符号的分数。**

「方向」列已经标了"负"，那是给你看的提醒，不是给公式用的。举例：

| 情况 | 怎么填 |
|---|---|
| 库存天数上升（恶化） | 得分填 **-1** |
| 库存天数下降（改善） | 得分填 **+1** |
| 应收账款周转天数上升 | 得分填 **-1** |
| 能源成本上涨 | 得分填 **-1** |

**自检方法**：填完问自己"这个分数代表景气变好还是变差？"——
正分必须是"对瓷砖行业景气是好事"。库存天数降了是好事，所以填正分。

### 3.4 用脚本交叉验证

```powershell
py -3.13 src/score.py
```

它会给出一份「建议得分」（`data/scorecard_auto.csv`）。

**用途不是替你决定，而是抓你的疏漏：**

- 脚本建议 +2、你填了 -2 → 回去查，多半是你把负向指标填反了
- 脚本说"无数据"、你填了分 → 你在凭印象打分，回去补数据
- 两者差的绝对值 ≥ 2 分 → 在「打分依据」里写清为什么你和规则不一样

**一致性比准确性更重要**：你和规则不一致可以，但每一次不一致都要有理由。

## 4. 第 3 周：LLM 证据抽取

### 4.1 先说清楚：这一周不要建 RAG

上一轮我建议过你，这里再强调一次：

你的 Docker 没装好（服务未注册、无 WSL 发行版），内存 16GB 已用 77%。
为 8 周项目折腾 Dify 是**负收益**。

**正确做法：文档少的时候，手动贴文本比 RAG 更可靠。**

理由很实在：RAG 检索错了，模型会拿错证据编出看起来合理的结论，而你还以为它有依据。
手动贴十页文档，只花 30 秒，而且**每一句话都能溯源**。

### 4.2 单文档抽取的标准动作（每份文档 5 步）

1. 打开 `prompts/01_evidence_extraction.md`，复制「系统提示词」
2. 粘贴到 API 对话框，设为 system message（或放最前面）
3. 把文档内容粘贴进去，外面套上用户提示词模板
4. 要求只输出 JSON，不要解释
5. 把 JSON 存成 `data/evidence/YYYY-MM-DD_来源_主题.json`

**一次只喂一份文档。** 十份塞一起，来源字段会串台，后面根本查不清。

### 4.3 溯源三分校验（每批 2 分钟，必做）

LLM 输出**永远不能直接信**。跑完做这三件事：

| 步骤 | 做法 | 抓什么 |
|---|---|---|
| ① 溯源 | 随机挑 3 条，回原文找那句话 | 编造、张冠李戴 |
| ② 查数 | 输出里每个数字回原文核对 | **幻觉数字**（最高发） |
| ③ 查类型 | 看「类型」列，观点有没有被标成事实 | 把研报观点当数据 |

**任一条过不了 → 整批作废重跑**，不要局部修补。
局部修补会让你误以为模型整体可靠，这是最危险的错觉。

### 4.4 这周实际要抽什么

按优先级，够用就行：

## 5. 第 4 周：合成季度报告

### 5.1 填写顺序（不要从上往下）

人的直觉是从"结论"开始写，这是错的。正确顺序：

```
评分卡（第2节） → 磨具映射（第4节） → 关键证据（第3节）
→ 分歧矛盾（第5节） → 风险反例（第6节） → 可证伪条件（第7节）
→ 结论（第1节） → 跟踪指标（第8节）
```

**结论最后写。** 先把数字和证据摆齐，结论是自然浮出来的，不是先定好再找理由。

### 5.2 每节的最低要求

| 节 | 最低要求 | 不合格的样子 |
|---|---|---|
| 1 结论 | 三句话：方向+置信度、耗材含义、模具含义 | "行业面临机遇与挑战" |
| 2 评分卡 | 12 行全填，依据不能空 | 只有总分没有明细 |
| 3 关键证据 | 利多利空各 ≥3 条，全带来源日期 | "据市场反馈" |
| 4 磨具映射 | 两个分都解释，说明是否背离 | 只写一个分 |
| 5 分歧矛盾 | 至少 1 组冲突，说清采信哪条 | 写"无明显分歧"（多半是没找） |
| 6 风险反例 | 四个盲点逐个过一遍 | 只写"政策风险" |
| 7 可证伪条件 | ≥3 条，有阈值有时间窗口 | "关注后续变化" |
| 8 跟踪指标 | 恰好 5 个，含数据来源和时间 | 列 20 个 |

### 5.3 让 LLM 写，但锁死边界

复制 `prompts/05_report_writing.md` 的 prompt，把评分卡、证据表、映射表填进去。

prompt 里有一句是关键：**"景气方向必须沿用评分卡给出的结论，不得自行改判"**。

跑完检查：报告里的方向词和「汇总」Sheet 的分级**是否一致**。
不一致就是模型自作主张了，重跑。

## 6. 第 5 周：磨具映射专项

### 6.1 两个分怎么解释

| 情形 | 含义 | 怎么写 |
|---|---|---|
| 耗材分高、模具分低 | 产量还行但没人扩产 | "耗材需求平稳，但设备端已在收缩，明年模具承压" |
| 耗材分低、模具分高 | 产量差但在扩产 | "短期耗材承压，但资本开支领先指标仍强，需确认是否为新产线" |
| 两个都低 | 全面收缩 | "耗材与模具同步走弱，行业进入下行" |
| 两个都高 | 全面扩张 | 小心：可能是周期性高点 |

**两者背离是常态，不是错误。** 产量是"现在"，资本开支是"未来"，本来就不该同步。

### 6.2 三情景写法

不要写"中性偏乐观"这种废话。写**可验证的情景**：

```
乐观（概率 30%）：地产竣工同比 Q4 转正 → 瓷砖产量跌幅收窄至 -3% 内 → 耗材需求 Q1 见底
中性（概率 50%）：竣工继续 -10% 左右 → 产量维持 -8% → 耗材需求继续下滑但速度放缓
悲观（概率 20%）：竣工跌幅扩大到 -20% → 产量 -15% → 耗材需求两位数下滑
```

**概率不用准，但三个情景的触发条件必须互斥、可观测。**

### 6.3 磨具端验证数据（滞后一个季度看）

| 公司 | 看什么 | 验证哪条链 |
|---|---|---|
| 奔朗新材 | 营收增速、毛利率、应收账款周转 | 产量 → 磨边耗材 |
| 科达制造 | 陶瓷机械收入 | 资本开支 → 压机模具 |

**如果瓷砖产量连跌两季但磨具营收没跌，先别喊"传导失效"，查三件事**：
库存缓冲、出口/海外产能、非瓷砖下游（石材玻璃）托底。

## 7. 第 6 周：验证与复盘

### 7.1 结算预测日志

打开 `forecast_log.xlsx`，把上季度登记的那条记录补完：

- **实际结果**：发生了什么（用数据说话，不写"基本符合预期"）
- **对错**：对 / 部分对 / 错 / 无法验证
- **错因分类**：从下拉里选

### 7.2 错因五分类怎么判

| 错因 | 判断标准 | 典型症状 |
|---|---|---|
| **数据问题** | 当时用的数就是错的 | 口径变了、把累计当单季、缺失当 0 |
| **逻辑问题** | 数对了，传导链断了 | 产量跌了但耗材没跌（被出口补上） |
| **时点问题** | 方向对了，早/晚了 | "我说会跌，确实跌了，但晚了两个季度" |
| **证据问题** | 关键反面证据没看到 | 红队没跑，或跑了但没当回事 |
| **运气** | 逻辑对、数据对，结果相反 | 突发政策、黑天鹅 |

**"运气"最多用一次。** 连续两次归因运气，说明你在骗自己。

### 7.3 改结构 vs 调权重（最重要的一条）

复盘后想改东西时，先问：

```
这个指标，是「我不该给它这么高权重」，还是「它根本不该在这个位置」？
```

| 症状 | 该做什么 |
|---|---|
| 某指标连续 2 次方向判断都错 | **改结构**：换指标，或增加一个新维度 |
| 某指标方向全对但幅度总不准 | **调权重**：小幅下调（一次不超过 5%） |
| 整体判断系统性偏乐观 | **查偏差**：不是调权重，是你自己在选择性看证据 |

> **8 个季度的样本量，调权重就是过拟合。**
> 每次只改一个地方，改完记录在「口径说明」Sheet 的变更日志里。

## 10. 卡住了怎么办

| 症状 | 原因 | 解法 |
|---|---|---|
| 某个指标死活找不到 | 数据确实不公开 | 标"代理"或"缺失"，**换一个能拿到的指标**，别硬撑 |
| 评分卡算出来是 0 | 所有得分正负抵消了 | 正常。说明行业真在中性区间，别为了"有结论"硬改分 |
| 景气分在 ±0.5 边界反复跳 | 权重太集中或数据噪声大 | 看趋势不看单月，连续两期同向才算转向 |
| LLM 老编数字 | 提示词不够硬 | 加"原文没有的数字写'未披露'"，并跑三分校验 |
| 报告写不出来 | 证据不够 | 回去补证据，不要用常识填空 |
| 觉得整个方法不可靠 | 正常，这就是行业研究的真实状态 | 把不确定性写进「局限性」，比假装确定强 |
| 没时间了 | 8 周本来就很紧 | 砍第 5 周（磨具专项），先保证第 4 周报告出来 |

## 11. 三条诚信红线

1. **不编数。** 拿不到就写缺失。一个假数字会毁掉整份报告的可信度。
2. **不藏反例。** 找到的利空证据必须写进报告，哪怕它推翻你的结论。
3. **不让 LLM 下结论。** 方向由你的评分卡定，模型只负责找证据和组织语言。
